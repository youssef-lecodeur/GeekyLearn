# 🚀 GeekyLearn

> Plateforme web interactive dédiée aux formations et à l'apprentissage de l'informatique.

## 📖 À propos du projet
**GeekyLearn** est un site web conçu pour centraliser et proposer des cours et formations en informatique. Le projet intègre un système complet de navigation, des pages d'authentification, un catalogue de formations ainsi qu'un tableau de bord (dashboard) utilisateur géré via une base de données dédiée.

## 📂 Structure du Projet
Le projet s'articule autour des fichiers suivants :
- `accueil.html` : Page d'accueil principale de la plateforme.
- `formations.html` : Catalogue et présentation des formations disponibles.
- `connexion.html` : Interface de connexion / authentification des utilisateurs.
- `dashboard.html` : Tableau de bord personnalisé pour le suivi des cours.
- `contact.html` : Page de contact et de support.
- `geekylearn.db` : Base de données du projet.
- Fichiers graphiques et de configuration (`.hintrc`, `clair.png`, `flechemenu.png`, etc.)[cite: 13].

## 🛠️ Technologies & Fonctionnalités
- **Frontend** : HTML5, CSS3 / Design d'interface utilisateur structuré (navigation par menus, dashboards).
- **Backend / Stockage** : Base de données SQLite (`geekylearn.db`).
- **Expérience Utilisateur** : Parcours fluide allant de la découverte des formations (`formations.html`) à l'espace membre (`dashboard.html`).
